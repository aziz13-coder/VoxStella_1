# Astrocartography Blog Traffic Plan

Date: 2026-04-07
Scope: SEO and content plan for Vox Stella's Astrocartography feature

## Core finding

Astrocartography traffic is not one keyword. It breaks into four distinct intents:

- definition intent: `what is astrocartography`, `relocation astrology`
- tool intent: `astrocartography map`, `astrocartography calculator`, `astrocartography app`, `astrocartography software`
- decision intent: `where should I move astrology`, `best places to live astrocartography`, `astrocartography for career/love/home`
- interpretation intent: `astrocartography lines meaning`, `local space astrology`, `parans astrology`, `relocation chart vs astrocartography`

Vox Stella already has one strong relocation explainer, but it does not yet have a full topic cluster. That means the site can rank for Astrocartography terms, but it is not yet structured to capture repeated search demand across beginner, evaluator, and conversion queries.

## Product angles worth marketing

The feature is strongest when described as a map-first decision workflow:

- world map with angular planetary lines
- optional transit overlay
- PathFinder goals for practical use cases
- atlas / best-city search
- compare tray for side-by-side city review
- inspector with relocation summary, local space, parans, and report view

The product language that should lead content is:

- `astrocartography`
- `relocation astrology`
- `compare cities`
- `best places to live`
- `where should I move`
- `location astrology`

The product language that should stay secondary is:

- `PathFinder`
- `parans`
- `local space`
- `intersections`

Those are valuable differentiators, but they are not usually the first phrase a new searcher uses.

## Current content gap

Current site coverage is good but narrow:

- product page mentions astrocartography, city comparison, and relocation goals
- features page describes map-first workflow, compare cities, local space, and nearby line effects
- blog currently has one main Astrocartography post:

What is missing:

- a dedicated tool-intent landing page for `astrocartography app / software / calculator`
- a line-meanings hub
- a `where should I move` decision post
- a `travel` angle post
- a clean `astrocartography vs relocation chart` comparison post
- deeper support posts for `local space` and `parans`

## What should be a page vs what should be a blog post

### Pages

Use pages for high-commercial-intent queries:

- `Astrocartography App`
- `Astrocartography Software`
- `Relocation Astrology Software`
- `Compare Cities with Astrocartography`

These searchers are closer to downloading or evaluating software.

### Blog posts

Use blog posts for informational and mid-funnel queries:

- `what is astrocartography`
- `how to read lines`
- `where should I move`
- `travel with astrocartography`
- `local space`
- `parans`

These posts should educate first, then route readers into the product workflow.

## Recommended post structures

### Structure for beginner / definition posts

Use this structure for `what is astrocartography`, `lines meaning`, and `relocation astrology` posts:

1. direct answer in the first 2 paragraphs
2. explain the key terms without jargon
3. show what a map actually shows
4. explain what the feature helps users do
5. add a practical step-by-step workflow
6. include mistakes / limitations
7. add FAQ
8. CTA into Vox Stella product or feature page

### Structure for decision posts

Use this structure for `where should I move`, `best places to live`, and `travel` posts:

1. start with the decision question exactly as searched
2. explain why one line is not enough
3. show the map -> inspect -> compare workflow
4. explain how to evaluate 2 to 5 candidate cities
5. add practical filters: budget, legal, family, job
6. include a small worked example
7. add CTA to compare cities in Vox Stella

### Structure for software / conversion pages

Use this structure for `astrocartography app` / `software`:

1. headline with the software-intent term
2. one-sentence promise: compare cities, inspect lines, and evaluate relocation options
3. screenshot of the map and inspector
4. feature blocks:
   - map-first world view
   - city comparison
   - PathFinder goals
   - local space and parans
   - report workflow
5. "How it works" in 3 steps
6. FAQ
7. licensing / platform CTA

## Angle decisions

### What to lean into

- map-first workflow
- compare cities before moving
- goal-based location reading
- practical inspection layers people miss
- desktop software for serious location astrology work

### What to avoid

- generic "best places in the world for you" claims
- overpromising outcomes
- overleading with niche terms before the basics are explained
- marketing hidden research-only models as finished travel logic

## Best CTA pattern

Do not end posts with a generic "download now".

Use CTA language that matches the post intent:

- for beginner posts: `See how Vox Stella maps and compares locations`
- for decision posts: `Compare your top cities in Vox Stella`
- for software pages: `Open the astrocartography workflow in Vox Stella`

## Practical conclusion

The biggest SEO opportunity is not writing more generic astrology content. It is building a clean Astrocartography topic cluster around:

- map / calculator / software intent
- city-comparison decision intent
- line-meaning interpretation intent

Vox Stella already has the product depth. The site just needs the content architecture to match the way people actually search for location astrology tools.
