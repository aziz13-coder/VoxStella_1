# Mundane Chart Type / Domain Lens Cheat Sheet

## Core Distinction

- `Chart Type` answers: what chart are we using?
- `Domain Lens` answers: what are we reading that chart for?

## Chart Type

- `War Event`
  - Use the outbreak / declaration / first-hostilities chart as the anchor.
- `Aries Ingress`
  - Use the annual Sun-enters-Aries chart as the public framework for the year.
- `Lunation`
  - Use a New Moon / Full Moon chart as a shorter trigger layer.
- `Eclipse`
  - Use an eclipse chart as a stronger trigger / activation layer.
- `National Chart`
  - Use the polity’s base chart as the main anchor.

## Domain Lens

- `War / Conflict`
  - Read for outbreak pressure, aggressor / defender structure, escalation, and reversals.
- `Government Stability`
  - Read for rulers, administration, crown / presidency, parliamentary disruption, and regime pressure.
- `Diplomacy / Foreign Affairs`
  - Read for treaties, allies, foreign entanglements, settlements, and diplomatic reversals.
- `Public Health`
  - Read for disease, hospitalization burden, epidemics, and mortality pressure.
- `Civil Unrest`
  - Read for riot, lawlessness, crowd instability, and civic disorder.
- `Finance / Economy`
  - Read for treasury strain, debt, collapse, and prolonged economic pressure.

## Mental Model

- `Chart Type` changes the chart being cast.
- `Domain Lens` changes the rule set used to judge that chart.

## Common Pairings

- `War Event` + `War / Conflict`
- `National Chart` + `Government Stability`
- `National Chart` + `Diplomacy / Foreign Affairs`
- `Aries Ingress` + `Government Stability`
- `Aries Ingress` + `Finance / Economy`
- `Eclipse` + `Public Health`
- `Lunation` + `Government Stability`

## Short Rule

- Ask `what chart is this?` -> pick `Chart Type`
- Ask `what question am I asking of it?` -> pick `Domain Lens`
