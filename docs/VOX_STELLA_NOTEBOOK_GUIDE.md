# Vox Stella Notebook Guide

Use the Notebook to review, search, and edit saved chart notes in one place.

## What You Can Do Here

Notebook is split into two panels:

- a note list on the left
- a note viewer and editor on the right

Only charts that already have notes appear in the list.

## Notes List

The notes list shows:

- the chart question
- the saved date
- a short preview of the note
- an enhanced-analysis marker when applicable

Use **Search notes...** to search both:

- chart questions
- note text

If there are no notes yet, Notebook shows an empty-state message. If notes exist but none match the search, it shows a no-results message.

## Opening A Note

Select any note in the left panel to load it into the editor on the right.

The chart header above the note shows:

- the question
- the saved date
- the verdict and confidence when the app is activated
- whether the chart used enhanced analysis

## Editing Notes

When a note is selected, you can:

- click **View Chart** to open the full horary workspace for that chart
- click **Edit** to modify the note
- click **Save** to store your changes
- click **Cancel** to discard the current edit and reload the saved note

Notebook supports plain text entry with Markdown-style formatting patterns shown under the editor, such as headings, lists, and links.

## Storage

Notes are saved locally with their charts on the current device or browser profile.
