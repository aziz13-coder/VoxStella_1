# Vox Stella Timeline Guide

Use the Timeline view to review saved horary charts in chronological order and look for repeating patterns in your practice.

## What You Can Do Here

Timeline View groups saved charts by date and lists the charts for each day from newest to oldest.

## Filters

At the top of the screen, Timeline shows a tag filter row.

- Select **All** to show every saved chart.
- Select a specific tag to limit the view to charts that include that tag.
- The chart count updates to match the current filter.

## How Charts Are Organized

Charts are grouped under sticky date headers. Within each date group, charts are ordered by their saved timestamp.

Each timeline entry can show:

- the question
- the chart time
- the verdict badge
- the confidence percentage when the app is activated
- tags
- an **Enhanced** badge when enhanced analysis was used
- a **Demo** badge when the chart was created in demo mode

## Opening A Chart

Click any timeline entry to open that chart in the horary workspace.

## Pattern Analysis

When at least one chart matches the current filter, the Timeline view shows a Pattern Analysis summary with:

- **Positive Outcomes**
- **Avg Confidence**
- **Solar Conditions**

These numbers update to reflect the currently filtered chart set.

## Empty State

If there are no saved charts for the current filter, the Timeline view shows an empty-state message instead of the grouped list.
