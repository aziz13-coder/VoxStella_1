## Blog Draft
Vox Stella 1.2.7 is a reliability update focused on making the app feel smoother in normal use.

This release is not about adding noise or complexity. It is about removing friction. A few issues users ran into during everyday work have now been cleaned up so the app behaves more predictably across Astro Clock, elections, activation, and updating.

If you use Vox Stella regularly, the main difference in this release is simple: fewer confusing moments, fewer false warnings, and a more stable experience when moving between charts, modes, and timing tools.

## What improved in this update

### A smoother election workflow
This update improves the election experience so successful scans are less likely to be interrupted by misleading error messages. The goal was to make elections feel clearer and more trustworthy during normal use, especially when working quickly and reviewing candidate times.

### Better Astro Clock behavior
We also tightened Astro Clock behavior around chart state changes. In previous edge cases, users could move from a snapped chart back toward realtime mode and feel unsure whether the clock had fully returned to the live state. This update improves that transition so the app behaves more consistently and feels easier to trust.

### More consistent chart handling
Some workflows were carrying too much ambiguity between one part of the app and another. This release improves consistency so chart results and supporting context stay better aligned across the app.

### Easier activation and update reliability
We also cleaned up parts of the activation and update experience so users can get into the app with less friction. The goal here was straightforward: if someone buys the software or downloads a new build, the path to getting up and running should feel simpler and more dependable.

## Why this release matters

Many software updates promise big things. This one is more practical.

Vox Stella is used for real decisions, real timing work, and real chart review. That means the small moments matter:

- when a scan succeeds, it should feel finished
- when you return to realtime, the app should feel clearly live again
- when you activate or update, the process should feel straightforward
- when you review a chart, the result should feel internally consistent

That is what 1.2.7 is for.

## How to update Vox Stella

If you already have Vox Stella installed:

1. Open the app.
2. Go to `Settings`.
3. Find the `Updates` section.
4. Click `Check for updates`.
5. If the new version is available, follow the prompt and restart the app when asked.

## If you prefer a fresh install

If you want to install the latest version again from scratch:

1. Visit [voxstella.app](https://voxstella.app/).
2. Download the latest installer.
3. Run the installer.
4. Open the app and activate it with your existing license key if needed.

For most users, reinstalling the latest version over the current one is enough. You usually do not need a complicated manual process.

## If the update does not appear immediately

If the in-app updater does not show the new release right away, the simplest path is to download the latest installer again from the website and install it directly.
