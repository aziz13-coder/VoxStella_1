## Blog Draft
Vox Stella 2.1.1 is built around a simple goal: make the app feel more dependable when you use it every day.

This update is less about noise and more about trust. We have spent this cycle tightening chart-heavy workflows, reducing friction in the interface, and refining the logic behind some of the most important research tools in the app.

If you already use Vox Stella regularly, the difference should feel practical rather than dramatic: faster Astro Clock behavior, steadier long sessions, cleaner modal workflows, and stronger interpretive consistency in key modules.

## What improved in 2.1.1

### Better performance and reliability where it matters most
One of the biggest focuses in this release was everyday performance.

Astro Clock has been tightened so the experience feels steadier during normal use, especially in the heavier workflows that depend on the live chart state. Startup behavior has improved, the app is more stable when moving between major workspaces, and the desktop flow has been refined so research features remain more responsive over longer sessions.

This is the kind of work users do not always see in a screenshot, but they feel it immediately in real use.

### Transit logic has been tightened
We also continued refining the transits workflow so it behaves more coherently across exact analysis, scan windows, and ranked prediction views.

In plain terms, the transit system is now better aligned with itself. The logic connecting one transit view to another has been tightened so the feature feels less fragmented and more trustworthy when you move from a single chart reading into a larger time window.

That does not mean the work is finished, but it does mean the transits engine is in a better place than it was before this pass.

### Astrocartography has become cleaner and more disciplined
Astrocartography also received another important refinement pass.

We improved both the logic and the presentation. On the logic side, the goal models were tightened against curated source-backed expectations so the feature behaves in a more deliberate way. On the frontend side, the modal workflow, city summary, workspace rhythm, and visual grouping were refined so the tool feels more integrated with the Astro Clock environment instead of behaving like a separate bolt-on.

The result is a feature that feels more coherent, both in how it looks and in how it reasons.

### The frontend has been polished across the heavier tools
This release also includes smaller but important interface refinements across chart-heavy areas of the app.

We have been cleaning up tile behavior, loading states, aspect displays, chart controls, and workspace transitions so the app feels more controlled and less awkward at the edges. These are not headline features on their own, but together they make the software easier to work with.

## About Weather and Mundo

You may notice early Weather and Mundo surfaces in the current build.

These models are still in the sketch phase. They are under active refinement and benchmarking, and we do not recommend relying on them yet for serious work.

They are promising directions, but they are not finished products. Better versions are expected after the next round of refinement, failure review, and benchmark expansion.

For now, they should be treated as early experimental tracks rather than stable production tools.

## Why this update is worth installing

Vox Stella is not only judged by the number of features it contains. It is judged by whether those features feel usable, coherent, and dependable when someone is actually working.

That is why this release matters.

2.1.1 improves the parts of the app that shape day-to-day trust:

- Astro Clock feels steadier.
- Transit logic is more coherent.
- Astrocartography is more refined.
- The interface is cleaner in the places where users spend real time.

If you are already using Vox Stella, this is a recommended update.

## How to update Vox Stella

If you already have Vox Stella installed:

1. Open the app.
2. Go to `Settings`.
3. Find the `Updates` section.
4. Click `Check for updates`.
5. Install the new version and restart the app when prompted.

If the updater does not show the new build immediately, the simplest fallback is to download the latest installer from [voxstella.app](https://voxstella.app/) and install it directly.
