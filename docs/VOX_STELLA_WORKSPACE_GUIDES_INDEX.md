## How The Sets Connect

- Start with **Dashboard** when you want to reopen saved horary work or move into the main app sections.
- Use **Cast A Chart** to create a new horary chart from question, place, and timing details.
- Use **Horary Workspace** to read, inspect, and annotate the cast result.
- Use **Settings** to verify the backend connection, manage activation, and handle updates.
- Use **Astro Clock** when you want the realtime or manual chart workspace and the deeper snap-aware tools built on that chart context.
