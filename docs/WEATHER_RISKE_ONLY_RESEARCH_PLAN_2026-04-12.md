## Scope Decision

Do not wait on Raman for the next weather-research step.

The active weather branch should proceed using the already converted Kris Brandt Riske text only:

- `horary_knowledge/weather_earthquake_books_text/Predicting_Weather_Events_with_Astrology_-_Kris_Brandt_Riske.txt`

This document records the first intake decision. It is no longer the active top-level plan because Bonatti and the supporting local corpus were later confirmed as additional usable weather/earthquake sources.

## Why This Is The Right Next Step

- the Riske source is already extracted and searchable
- it contains explicit method structure, event-type chapters, and worked examples
- it is strong enough for doctrine inventory and benchmark-prep work
- waiting on the Raman extraction blocker would stall useful research work that can already be done

## What To Do With The Riske Corpus Now

### 1. Build a weather doctrine inventory

Extract and normalize the source into a reusable memo covering:

- chart types used
- timing model used
- locality and map logic
- event families covered
- explicit planet/aspect-to-weather mappings
- explicit limits and cautions

### 2. Build a candidate case inventory

Do not create benchmark packs yet, but identify candidate historical weather examples already present in the book:

- wind
- drought
- floods
- temperature extremes
- hurricanes
- snow / freezing precipitation
- thunderstorms / hail / tornadoes

### 3. Separate weather from earthquakes

Weather can move into doctrine extraction now.

Earthquakes remain blocked until another usable source is available.

### 4. Keep the gate honest

The weather branch is not benchmark-first yet.

It becomes benchmark-first only after:

1. a source-alignment memo is complete
2. candidate weather cases are inventoried cleanly
3. at least one more usable source family is available, or the current source proves unusually explicit and historically anchored enough to justify a narrow seeded benchmark pack
