# National Chart Candidates

Status: first pass

## Purpose

This file records the current candidate national charts that are explicit enough in the present corpus to support benchmarking and overlay testing.

It does not claim that all of these are final or uncontested. The purpose is narrower:

- make candidate charts explicit
- preserve source preference and disagreement
- support benchmarked comparison instead of ad hoc chart choice

## Working Rule

If a polity has more than one defensible chart:

1. keep every candidate with source provenance
2. record which source prefers which chart
3. test candidate charts against benchmark cases rather than selecting by taste
